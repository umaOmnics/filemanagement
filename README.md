# File Management Package

Reusable file management package for Laravel applications.

## Overview
A Composer package (omnics/filemanagement) providing reusable file management functionality for Laravel apps, with an auto-registered service provider (FileManagementServiceProvider).

## Requirements
- PHP ^8.0
- Laravel (illuminate/support, illuminate/routing, illuminate/database ^10.0 or ^11.0)

## Installation
composer require omnics/filemanagement

## Tech stack
PHP, Laravel, Composer
